# Boss

One project, two models: take a dataset the tutor approves, solve it with a classical model and with a neural network, and defend the choice between them in a short report.

Passes when:

- both models are evaluated on the same held-out split with intervals
- the report explains the result using bias-variance and the size of the data
- everything reproduces from a clean clone with one command
