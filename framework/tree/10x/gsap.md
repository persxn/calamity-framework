# Scope

What the mastery standard covers. The learner's own syllabus is written from this list
and from current official documentation when they start the skill.

- tweens: to, from, fromTo; easing
- timelines and sequencing; labels
- ScrollTrigger: pinning, scrubbing
- working inside a component framework: contexts and cleanup
- performance and `prefers-reduced-motion`

# Boss

Build an animated landing section with a scrubbed scroll timeline.

Passes when:

- animations hold 60 fps
- reduced-motion preference is respected
- timelines are cleaned up on unmount
