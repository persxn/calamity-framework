# Scope

What the mastery standard covers. The learner's own syllabus is written from this list
and from current official documentation when they start the skill.

- the utility-first workflow; configuration and theme tokens
- responsive, state and dark-mode variants
- layout and typography utilities; arbitrary values
- extracting components instead of repeating class lists; plugins
- production output size and how unused styles are dropped

# Boss

Restyle an existing app with Tailwind from a design brief.

Passes when:

- no hand-written CSS beyond theme tokens
- the production CSS is under 20 kB gzipped
- the layout is correct at three breakpoints
