# Scope

What the mastery standard covers. The learner's own syllabus is written from this list
and from current official documentation when they start the skill.

- semantic HTML: document structure, headings, links, lists, tables, media, metadata
- forms: inputs, labels, validation attributes
- accessibility basics: labels, alt text, landmarks, focus order
- CSS fundamentals: selectors, specificity, the cascade, inheritance, the box model
- layout: flexbox, grid, positioning
- responsive design: fluid units, media queries, container queries
- typography, colour, custom properties, transitions and simple animations
- debugging layout in browser devtools

# Boss

Build a responsive three-page site from a written design brief, with no framework and no CSS library.

Passes when:

- the HTML validates (W3C validator or `html-validate`)
- Lighthouse accessibility score is 90 or more
- the layout holds at 360px and at 1280px with no horizontal scroll
- a keyboard-only walkthrough reaches every interactive element
