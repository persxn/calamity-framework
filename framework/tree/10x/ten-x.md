# Boss

One project that uses the whole path: write the design document, build it, review its security, ship it through a pipeline to infrastructure you defined as code, and operate it for two weeks with real monitoring.

Passes when:

- the design document predates the code and its trade-offs held up
- every earlier capstone check passes on this system
- a written incident review exists for at least one real or injected failure
- someone else can deploy it from the README alone
