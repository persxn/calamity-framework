# Scope

What the mastery standard covers. The learner's own syllabus is written from this list
and from current official documentation when they start the skill.

- project structure, Gradle, the manifest
- Compose: composables, state, layouts, lists, theming
- navigation
- the activity lifecycle; configuration changes
- permissions; resources and localisation

# Boss

Build a three-screen app with a list, a detail view and a form.

Passes when:

- state survives rotation
- the UI works at two screen sizes and in dark mode
- lint reports nothing serious
