# Scope

What the mastery standard covers. The learner's own syllabus is written from this list
and from current official documentation when they start the skill.

- motion components, animate, transition
- variants and orchestration
- layout animations and shared layout
- AnimatePresence and exit animations
- gestures, scroll-linked animation
- performance and `prefers-reduced-motion`

# Boss

Add meaningful motion to the React app: page transitions, a list reorder, one gesture.

Passes when:

- animations hold 60 fps in the performance panel
- reduced-motion preference is respected
- no layout shift is introduced (CLS unchanged)
