# Scope

What the mastery standard covers. The learner's own syllabus is written from this list
and from current official documentation when they start the skill.

- complexity analysis in time and space
- arrays, strings, hashing
- stacks, queues, linked lists
- recursion and backtracking
- sorting and binary search
- trees, heaps
- graphs: breadth-first and depth-first search
- dynamic programming in outline
- problem-solving patterns: two pointers, sliding window, prefix sums

# Boss

Sit a timed set of eight problems that mixes every structure in the scope.

Passes when:

- six of eight are solved within the time limit
- each solution states its complexity correctly
