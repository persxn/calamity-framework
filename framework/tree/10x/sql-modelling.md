# Scope

What the mastery standard covers. The learner's own syllabus is written from this list
and from current official documentation when they start the skill.

- tables, keys, relationships
- SELECT: filtering, joins, aggregation, subqueries, common table expressions, window functions
- DDL and constraints: primary and foreign keys, unique, check
- normalisation and when to denormalise
- indexes in outline
- transactions and isolation levels

# Boss

Design a schema for a domain the tutor names and answer ten business questions with queries.

Passes when:

- every table has a primary key and the right foreign keys
- each question has one correct query
- the schema is in third normal form, or each exception is justified in writing
