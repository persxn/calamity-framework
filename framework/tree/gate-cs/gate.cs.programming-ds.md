# Topics

## c-programming | Programming in C
level: 2
- types, operators and precedence, control flow, functions and parameter passing
- pointers, arrays, strings, structures, scope and storage classes; trace what a program prints

## recursion | Recursion
level: 2
- trace recursive calls; count calls and stack depth; write the recurrence

## arrays | Arrays
level: 2
- row-major and column-major address calculation; operations and their costs

## stacks | Stacks
level: 2
same_as: [gate.da.programming-dsa/stacks]
- push and pop; expression evaluation and conversion; valid stack permutations

## queues | Queues
level: 2
same_as: [gate.da.programming-dsa/queues]
- linear and circular queues; queues from stacks and the reverse

## linked-lists | Linked lists
level: 2
same_as: [gate.da.programming-dsa/linked-lists]
- insert, delete and reverse in singly and doubly linked lists; trace pointer code

## trees | Trees
level: 2
same_as: [gate.da.programming-dsa/trees]
- binary trees and their traversals; rebuild a tree from two traversals; height and node counts

## binary-search-trees | Binary search trees
level: 2
- search, insert and delete; inorder gives sorted order; best and worst heights

## binary-heaps | Binary heaps
level: 2
- array form; heapify; build-heap in O(n); insert and delete in O(log n)

## graphs | Graphs
level: 2
- adjacency matrix and list; space and time trade-offs of each
