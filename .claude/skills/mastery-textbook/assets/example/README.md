# Markup example (not a depth example)

A tiny chapter showing every convention in use, compiled from the template:
`chapters/ch01-ls.tex`, its solutions, one SVG figure, one bibliography entry, and the rendered result (`example-render.pdf`).

It is deliberately short. A real chapter follows the full anatomy in `references/writing-standard.md` and is many times longer.
To try it: copy `assets/template/` to a new folder, add these files, include the chapter and solutions in `main.tex`, append the entry to `refs.bib`, and run `scripts/build.sh`.
